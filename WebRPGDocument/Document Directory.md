# Document Directory

- 用途：供 AI 按任務讀取遊戲設計，減少不必要的上下文。
- 適用範圍：WebRPGDocument 內的文件索引與 AI 閱讀流程；本文件內的連結皆相對於本目錄。

## 文件索引

| 文件 | 內容 | 何時讀取 |
| --- | --- | --- |
| [Coding 規則](CodingRules.md) | SOLID、命名、程式風格、註解、相容性與通訊一致性 | 撰寫、修改或審查程式碼前必讀 |
| [Git 規則](GitRules.md) | Commit 命名與提交前確認 | Git Commit 前必讀 |
| [Unity 規則](UnityRules.md) | 修改影響範圍、自動產生資料夾與既有內容保護 | 修改 `WebRPG/` 內的 Unity 專案檔案前必讀 |
| [文件撰寫格式範例](DocumentTemplate.md) | 文件撰寫原則與可複製範本 | 新增或修改設計與技術文件前閱讀 |
| [主玩法](CoreGameplay.md) | 核心循環、玩家目標、規則與驗收情境 | 討論或修改主要遊戲行為時 |

## 規則

- 1：先遵守專案根目錄的 [AGENTS.md](../AGENTS.md)。
- 2：依上方索引選讀相關文件，不預先讀取所有文件；是否需要重讀，依根目錄 AGENTS.md 的「AI 文件閱讀流程」判斷。
- 3：「範例」供討論；「待確認」表示尚無決定；兩者均不可直接實作。
- 4：「已核定」代表設計已獲同意，不代表程式已完成。
- 5：實作前閱讀相關原始碼與設定；發現文件與程式不一致時指出差異。
- 6：每項規則維持單一來源；新增主題時拆成獨立文件並更新本索引。
