# 主玩法

- 設計狀態：待確認；待確認項目不可據此直接實作。
- 實作狀態：未確認。
- 用途：定義核心循環、玩家目標與主要系統的關係；各系統細節另行定義。

## 玩法摘要

本作為 2D 掛機自動戰鬥 RPG，玩家可自行設定半掛機或全掛機模式。玩家透過打怪取得經驗值、裝備、素材與金幣，藉由升級、屬性配點、裝備配置及打造提升能力，再挑戰更強的怪物。

世界地圖由城鎮、地牢等節點構成。節點之間的移動與地牢探索統稱為「旅程」。旅程依設定採用隨機或固定的遭遇次數，從遭遇池抽選敵人，獎勵從獎勵池抽選。只有地牢旅程在最後設有地牢領主，擊敗後可取得特別寶箱。抵達節點後，玩家可執行該節點提供的活動。

玩家隊伍與敵方隊伍各最多 4 人。玩家可線上組隊一起刷怪，組隊時敵人數值依公式增強。

半掛機模式由玩家在戰鬥結算時查看及領取獎勵；全掛機模式依玩家設定自動篩選及領取獎勵。自動化僅在當次旅程內生效，目前不製作自動重複旅程與離線掛機功能。

## 核心循環

規劃旅程與自動化設定 → 依序自動戰鬥與處理獎勵 → 完成旅程並執行節點活動 → 配點與裝備整備 → 挑戰更強的旅程。

地牢旅程在最後加入地牢領主戰，勝利後提供特別寶箱。

半掛機模式由玩家手動處理結算與獎勵收納；全掛機模式依玩家設定自動篩選及領取獎勵。

玩家可在規劃旅程時設定自動化模式，也可在旅程進行中調整。

組隊時由隊長選擇行動，隊長不須另外按下準備；其他隊員按下準備後才可出發。戰鬥後的領獎斷點亦須等待其他隊員準備後才繼續。

城鎮提供裝備買賣、素材打造及商城抽獎，支援玩家整備與取得物品。

## 玩家目標

- 短期：透過自動戰鬥取得經驗值、裝備、素材與金幣。
- 中期：調整屬性配點、更新裝備並整理背包，提升角色能力。
- 長期：持續成長，挑戰更強的怪物與地牢。

## 主要系統

| 系統 | 在主玩法中的用途 |
| --- | --- |
| 數值屬性與配點 | 角色具有力量、敏捷、體質、智力、運氣五種屬性，玩家透過配點調整成長方向。 |
| 等級與經驗值 | 玩家具有等級與經驗值，等級上限為 100。 |
| 裝備 | 透過怪物掉落或城鎮素材打造取得裝備，提升角色能力。 |
| 背包 | 分為物品會生效的裝備區與物品不會生效的背包區。初始尺寸分別為寬 10 × 高 5 格與寬 10 × 高 10 格，尺寸可由資料設定，裝備區可透過升級擴大。 |
| 物品 | 定義裝備、打造素材、藥水及其他物品的用途與使用規則；部分物品可堆疊。 |
| 貨幣 | 分為打怪取得的金幣，以及透過儲值或其他特別管道取得的稜晶。 |
| 地圖與節點 | 以 JSON 設定節點、雙向連接關係及節點活動；UI 讀取資料後動態產生與排列地圖畫面。 |
| 旅程 | 統一管理節點移動與地牢探索，支援隨機或固定遭遇次數、遭遇與獎勵抽選，以及中途終止；地牢旅程另有領主與特別寶箱。 |
| 自動戰鬥 | 支援半掛機與全掛機，每次攻擊以單一單位為目標；玩家可設定激進、保守等策略與優先攻擊的敵人種類。 |
| 線上組隊 | 支援最多 4 名玩家一起刷怪、隊長設定目的地、隊員準備與全員同意終止旅程；敵方隊伍最多 4 人，敵人數值依組隊公式增強。 |
| 內購與商城 | 在城鎮商城提供購買箱子並開箱抽獎的機制。 |
| 系統設定資料 | 採 JSON 資料驅動方式管理遊戲設定，方便調整玩法內容與平衡。 |
| 玩家資料保存 | 將裝備資料等玩家關鍵資料保存在資料庫。 |

## 規則

- 1：戰鬥採自動進行。玩家可自行設定半掛機或全掛機模式，目前不製作離線掛機功能。
- 2：擊敗怪物可取得經驗值與金幣，並有機會取得裝備與素材。
- 3：角色可透過升級、屬性配點及裝備提升能力，逐步挑戰更強的怪物。
- 4：裝備可由怪物掉落，或在城鎮使用素材打造。
- 5：背包分為裝備區與背包區。放在裝備區的物品會生效，放在背包區的物品不會生效。
- 6：世界地圖由多個節點構成，節點包含城鎮與地牢。
- 7：節點之間的移動與地牢探索統稱為旅程。旅程可設定採用隨機或固定的遭遇次數，遭遇從設定好的遭遇池抽選。
- 8：玩家抵達節點後，可執行該節點提供的活動。
- 9：只有地牢旅程在最後設有地牢領主，擊敗後可取得特別寶箱；一般節點移動旅程不設結尾領主與寶箱。
- 10：城鎮提供購買裝備、販售裝備及使用素材打造裝備的功能。
- 11：貨幣分為金幣與稜晶，兩者無法互相轉換。金幣可透過打怪取得，稜晶可透過儲值取得；稜晶的其他特別取得管道之後另行設計。
- 12：遊戲包含內購機制，玩家可在城鎮商城購買箱子並開箱抽獎；支付方式與抽獎內容待確認。
- 13：玩家可透過線上組隊一起刷怪，玩家隊伍與敵方隊伍各最多 4 人。玩家組隊時，敵人數值依公式增強；具體公式與獎勵分配方式待確認。
- 14：半掛機模式在戰鬥勝利後顯示結算畫面，由玩家查看及領取獎勵。物品獎勵必須放入背包；空間不足時，玩家須丟棄不需要的物品，才能收納欲保留的獎勵。
- 15：全掛機模式依玩家設定自動篩選及領取獎勵；篩選條件與空間不足時的處理方式待確認。
- 16：戰鬥全程自動進行，不提供手動介入戰鬥的選項。每次攻擊以單一單位為目標，單人與組隊戰鬥皆適用。玩家可設定激進、保守等自動行為策略，以及優先攻擊的敵人種類；各策略與目標優先序的具體規則待確認。
- 17：戰鬥失敗時不產生該場戰鬥獎勵，玩家返回上一個到達的城鎮，不附加其他懲罰，回城後角色狀態亦無懲罰。新玩家初始位置位於城鎮；每次到達新的城鎮時，覆寫回城目的地。
- 18：部分物品可堆疊，例如素材與藥水；各物品是否可堆疊及堆疊上限另行定義。
- 19：WebSocket 連線斷開即判定為玩家斷線。玩家在戰鬥途中斷線時視為戰敗，依規則 17 處理。組隊旅程中任一隊員斷線時，當次全隊旅程立即以失敗中斷。
- 20：旅程中的戰鬥獎勵從設定好的獎勵池抽選；抽選方式與各項機率另行定義。
- 21：玩家可在旅程開始前的規劃介面設定半掛機或全掛機，也可在旅程進行中調整；調整的生效時機待確認。
- 22：遊戲系統設定採 JSON 資料驅動方式。旅程遭遇次數模式與數值、遭遇池、地牢領主、獎勵池，以及組隊敵人強化公式的參數等，須可透過設定資料調整。
- 23：自動化僅在當次旅程內生效，不自動重複旅程。玩家手動停止或戰敗時，自動化停止；組隊中終止旅程須符合規則 26。
- 24：組隊時由隊長選擇行動與設定移動目的地，隊長選擇行動後不須另外按下準備；其他隊員須按下準備後才可開始旅程。
- 25：組隊戰鬥後的領獎斷點，須等待其他隊員按下準備後才繼續。
- 26：旅程可隨時提出終止；單人可直接終止，組隊則須全員同意後才終止。
- 27：地圖節點之間的連接皆為雙向。地圖資料記錄各節點及其連接的所有節點，UI 讀取資料後動態產生並排列地圖畫面。
- 28：裝備區初始尺寸為寬 10 × 高 5 格，背包區初始尺寸為寬 10 × 高 10 格。兩區尺寸皆可透過 JSON 設定調整，裝備區另可透過升級擴大。
- 29：每名玩家可分別設定自己的自動戰鬥目標優先序，指定優先攻擊的敵人種類；組隊時各自依設定選擇目標。
- 30：裝備資料等玩家關鍵資料須保存在資料庫；完整保存範圍與寫入時機另行定義。
- 31：玩家屬性包含力量、敏捷、體質、智力、運氣。
- 32：玩家具有等級與經驗值，等級上限為 100；升級所需經驗值與滿級後經驗值的處理方式另行定義。

## 驗收情境

- 對應規則 1：玩家可設定半掛機或全掛機模式，兩種模式皆無須逐次下達攻擊指令。
- 對應規則 2：擊敗怪物後，玩家可確認取得的經驗值、金幣及掉落物品。
- 對應規則 3：升級、配點或更換裝備後，角色能力依對應系統規則更新。
- 對應規則 4：玩家可分別透過怪物掉落與城鎮打造取得裝備。
- 對應規則 5：物品放入裝備區後產生對應效果，移至背包區後不再產生該效果。
- 對應規則 6、7：節點移動與地牢探索皆以旅程進行，遭遇次數符合設定的隨機或固定模式，遭遇來自指定遭遇池。
- 對應規則 8、9：一般移動旅程完成後抵達目的節點；地牢旅程最後出現地牢領主，擊敗後可取得特別寶箱。
- 對應規則 8、10、11：抵達城鎮後，玩家可買賣裝備，並使用素材打造裝備；交易依貨幣規則結算。
- 對應規則 11：打怪可取得金幣，完成儲值後可取得對應的稜晶。
- 對應規則 11：金幣與稜晶之間不存在互相轉換的功能。
- 對應規則 12：玩家可在城鎮商城購買箱子，開箱後可確認抽獎結果與取得的獎勵。
- 對應規則 13：玩家可組成最多 4 人的隊伍，無法加入第 5 人；敵方配置亦不超過 4 人，組隊敵人數值符合強化公式。
- 對應規則 14：半掛機戰鬥勝利後顯示結算畫面；空間不足以收納欲領取的物品時，玩家可丟棄不需要的物品後完成收納。
- 對應規則 15：全掛機戰鬥結束後，系統依玩家設定篩選及領取獎勵。
- 對應規則 16：角色依設定的策略自動戰鬥，每次攻擊只以一個單位為目標；戰鬥介面不提供手動介入戰鬥的操作。
- 對應規則 17：新玩家從城鎮開始遊戲；到達另一座城鎮後，回城目的地更新為該城鎮。戰敗不產生該場獎勵，玩家返回記錄的城鎮，不額外扣除經驗值、貨幣或已持有的物品，角色狀態亦無懲罰。
- 對應規則 18：相同且可堆疊的物品可合併存放，數量不得超過該物品的堆疊上限。
- 對應規則 19：WebSocket 連線斷開時即觸發斷線處理；單人戰鬥途中斷線時依戰敗處理，組隊旅程中任一隊員斷線時，全隊當次旅程立即以失敗中斷。
- 對應規則 20：旅程戰鬥產生的獎勵符合指定獎勵池與抽選規則。
- 對應規則 21：玩家可在規劃介面設定自動化模式，並於旅程中修改，依規定的生效時機套用。
- 對應規則 22：調整旅程與戰鬥相關 JSON 設定後，遊戲依更新後的設定執行；設定載入及生效方式另行定義。
- 對應規則 23：旅程完成後不自動開始下一次旅程；手動停止或戰敗後，自動化停止。
- 對應規則 24：隊長選擇行動後，不須另外按準備；其他隊員全部準備後即可開始旅程，只要仍有其他隊員未準備就不開始。
- 對應規則 25：組隊戰鬥後停在領獎斷點，只要有其他隊員尚未準備，就不繼續。
- 對應規則 26：單人可於旅程中終止；組隊提出終止後，須全員同意才終止。
- 對應規則 27：相連的兩個節點可雙向移動；調整節點及連接資料後，地圖 UI 依資料動態產生節點、連線與排列。
- 對應規則 28：初始裝備區為寬 10 × 高 5 格，背包區為寬 10 × 高 10 格；修改尺寸設定後依設定產生空間，裝備區升級後依升級規則擴大。
- 對應規則 29：組隊中的玩家可設定不同的優先敵人種類，各角色依自己的設定選擇攻擊目標。
- 對應規則 30：玩家裝備資料寫入資料庫後，重新登入仍可載入已保存的裝備資料。
- 對應規則 31：玩家可查看力量、敏捷、體質、智力、運氣五種屬性及其數值。
- 對應規則 32：玩家可查看等級與經驗值，等級不得超過 100。

## 待確認

- 掛機：旅程中變更自動化設定的生效時機，以及手動停止自動化與終止旅程的操作關係。
- 戰鬥：自動技能使用方式、激進與保守等策略的具體行為、敵人種類分類、目標優先序設定方式，以及無符合目標或同優先序時的選擇規則。
- 結算與領獎：全掛機篩選條件、未領取獎勵的處理方式、背包空間不足時的自動處理，以及物品獎勵可放入的區域。
- 成長：各屬性的效果與初始值、配點取得與重置方式、初始等級、升級所需經驗值，以及滿級後經驗值的處理方式。
- 裝備與打造：裝備部位、品質、隨機屬性、打造成本與產出規則。
- 背包：物品形狀、旋轉、可放入的物品類型、區內擺放位置是否影響物品效果，以及裝備區升級的條件、成本、擴大方式與上限。
- 物品：完整分類、取得與使用方式，以及各類物品的堆疊條件與上限。
- 貨幣：金幣與稜晶的用途、交易價格，以及稜晶的其他特別取得管道。
- 地圖：移動時間，以及 UI 動態排列方式。
- 旅程：隨機遭遇次數的範圍與抽選方式、地牢遭遇次數是否包含領主戰、遭遇與獎勵池的抽選規則，以及主動終止時的返回位置與進度處理。
- 地牢：特別寶箱的內容與領取方式。
- 商城與抽獎：支付方式、箱子種類、獎池、機率、重複獎勵與保底規則。
- 組隊：戰鬥參與方式、敵人強化公式、獎勵分配、個別角色被擊敗與全隊戰敗的判定，以及全掛機模式與隊員準備確認的互動方式。
- 組隊流程：準備狀態的重置時機、終止提案的拒絕與逾時處理，以及失敗中斷後各隊員的回城位置。
- 連線：單人非戰鬥期間斷線的處理，以及重新連線後的恢復流程。
- 資料驅動：JSON 結構、編輯與驗證方式、載入時機，以及調整是否影響進行中的旅程。
- 玩家資料保存：除裝備外的關鍵資料範圍、資料庫寫入時機，以及保存失敗時的處理方式。
