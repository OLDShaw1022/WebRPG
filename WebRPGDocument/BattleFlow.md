# 戰鬥行動與時間控制

- 設計狀態：已核定；依本次玩家鎖定、手動技能與敵人意圖需求。
- 實作狀態：部分實作；單人戰鬥核心與介面接入，正式美術及多人戰鬥未實作。
- 適用範圍：單人冒險戰鬥的動作排程、目標、效果結算與時間。
- 用途：作為戰鬥行為的單一規格來源；介面配置見[挑戰介面](AdventureUI.md)。

## 規則

- 1：每位存活角色同時僅施放一個動作。普攻與技能各有施放時間；技能另有獨立冷卻，普攻沒有冷卻。
- 2：玩家開戰時自動開始普攻，技能立即可用；技能不自動施放。玩家點選可用技能時取消正在施放的普攻並從頭施放技能；正在施放的技能不能中斷，也不排入另一個技能。
- 3：技能施放完成即開始冷卻，玩家恢復普攻；其他技能冷卻與目前動作可以同時推進。點擊冷卻中或未裝備的技能不改變目前動作。
- 4：點擊存活敵人卡鎖定，目標保持到玩家改選或該敵人死亡。開戰或鎖定目標死亡時，選目前生命絕對值最低的存活敵人；相同生命依原陣列順序。點擊死亡敵人或無效識別不改變鎖定。
- 5：切換鎖定不重置讀條，傷害動作在施放完成時取得當下鎖定目標；已發射的投射物維持原目標。治療回復施放者自身生命，不能超過生命上限。
- 6：施放完成產生單一投射物；傷害與治療在飛行結束後一起結算。治療動作的佔位投射物在自身位置停留相同期間，表示效果尚未結算。
- 7：投射物期間暫停所有角色施放、技能冷卻與戰鬥時限倒數，只推進投射物。多個動作同時完成時依玩家、敵人原排列順序逐一播放；先結算的攻擊若擊倒後續攻擊者，該敵人的動作取消。
- 8：每位敵人的特殊技能由自己的設定決定；完成指定次數普攻且特殊技能冷卻結束後，下一個動作改成特殊技能。次數以普攻結算為準，特殊技能結算後重置；冷卻未完成時繼續普攻，待下一個動作選擇時檢查。
- 9：敵人開戰時特殊技能冷卻為零，但須先完成設定的普攻次數；特殊技能施放完成開始冷卻。敵人技能效果不使用玩家技能等級成長。
- 10：時間控制提供暫停、1 倍與 2 倍，影響模擬時間與投射物；不修改全域 Time.timeScale。暫停時仍可切換鎖定及選擇可用技能，以便調整策略。
- 11：中央選單暫停為獨立狀態，包含投射物；關閉後維持原時間控制選擇，不強制回到 1 倍。查看地圖仍沿用目前速度，不額外暫停。
- 12：每場戰鬥重新開始普攻、技能立即可用；不沿用上場的讀條或冷卻。新一輪挑戰速度回到 1 倍。
- 13：施放、冷卻與投射物秒數皆由 AdventurePrototype.json 設定；目前使用較長施放時間方便判讀，屬原型數值，不代表正式平衡。

## 設定

| 路徑 | 用途 |
| --- | --- |
| BasicAttack.Damage／CastTime | 玩家普攻傷害與施放秒數。 |
| Skills[].CastTime／Cooldown | 玩家技能施放秒數與施放完成後的冷卻。 |
| Enemies[].CastTime | 敵人普攻施放秒數。 |
| Enemies[].SpecialSkill | 專屬技能名稱、效果、施放、冷卻及 BasicAttacksBeforeUse 普攻次數；可為 null。 |
| ProjectileTravelTime | 每次效果結算前的飛行秒數。 |
| SimulationStep／BattleTimeLimit | 固定模擬步長及不包含投射物的戰鬥時限。 |

## 驗收情境

- 對應規則 1～3：普攻讀條途中點可用技能，普攻不命中；技能中點其他技能不改變動作；完成技能後恢復普攻並顯示冷卻。
- 對應規則 4、5：改選敵人不重置讀條；死亡目標自動切到生命最低的存活敵人；飛行中改選不改變該次受擊者。
- 對應規則 6、7：投射物抵達前生命不變，所有倒數保持；結算後恢復倒數，同步完成的動作依規定順序處理。
- 對應規則 8、9：tooltip 預告的普攻次數逐次減少，之後讀條切成敵人特殊技能；回血不超過上限。
- 對應規則 10～12：暫停與倍速同樣影響投射物；開關選單不覆寫速度選擇；新戰鬥技能立即可用。
- 對應規則 13：改動設定後，下一輪挑戰使用新的施放、冷卻、普攻次數與飛行秒數。
