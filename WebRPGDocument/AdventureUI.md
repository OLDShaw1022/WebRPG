# 挑戰介面

- 設計狀態：已核定；依使用者指定的《Slay the Spire》參考方向與本次已核准的 UI 調整整理。
- 實作狀態：部分實作；單人與多人角色資料及操作已接入；正式美術仍待製作。
- 適用範圍：挑戰中的地圖、戰鬥、節點處理、獎勵與結算介面。
- 用途：定義資訊位置與互動；玩法規則見[主玩法](CoreGameplay.md)，配色與美術風格見[美術製作規範](ArtProductionRules.md)。

## 規則

- 1：挑戰介面採上、中、下的排列，右側固定顯示可垂直捲動的戰鬥紀錄，其餘主要 UI 保留在左側。參考《Slay the Spire》的地圖與戰鬥配置方向，不據此加入卡牌、手牌或回合制玩法。
- 2：地圖使用獨立畫面，不與戰鬥場景並排。需要選擇下一節點時顯示地圖；挑戰中可透過上方按鈕查看地圖並返回原畫面。
- 3：地圖由下往上呈現各列節點與連線，區分可前往、已選擇、已略過及未到達節點；記錄實際所選路徑，不只用顏色區分狀態。僅選路階段的目前列可操作；其他列及戰鬥中檢視的地圖僅供查看。
- 4：畫面上方的玩家數值框橫跨整個螢幕寬度，摘要由左至右依序為本機玩家、目前／最大生命、金幣、目前／總樓層，樓層置於最後；不顯示攻擊、技能數與遺物數。地圖與選單按鈕並排置於此框右側。指向其他角色時，不將上方替換為該角色的資料。
- 5：戰鬥區玩家固定在左、敵人固定在右，各方最多使用 2×2 格位，角色卡固定為 176×170，不縮放、不捲動；每張卡下方依序顯示名稱、血條與目前動作施放條。VS 固定在角色區正中央；戰鬥框頂部保留時間控制列。多人顯示實際房內隊員的獨立生命與動作；單人只顯示本機玩家。
- 6：畫面下方以固定 88×112 圖示卡呈現技能狀態，預設一次顯示本機玩家的普攻與六個技能槽，不縮放、不捲動。普攻獨立顯示，不占技能槽；技能使用暫用方塊，下方常駐名稱；未裝備欄位標示「空槽」，指向時顯示「尚未裝備」。
- 7：游標指向敵人顯示目前行動敘述 tooltip，另以分隔線區分特殊技能預告，列出剩餘普攻次數、特殊技能效果與冷卻；下方技能列固定為本機玩家。點擊存活敵人卡鎖定，紅框及「鎖定」文字標示目前目標，移開游標不解除。
- 8：上方本機生命以文字呈現；角色生命以血條及數字呈現。角色下方施放條由空至滿並顯示動作名稱、剩餘秒數；下方技能卡另顯示冷卻及「可施放／施放中／待戰」文字，空槽及擊倒狀態須明確。普攻沒有冷卻；動作與時間規則見[戰鬥行動與時間控制](BattleFlow.md)。
- 9：技能卡可點擊以施放；冷卻中、空槽及玩家正施放其他技能時不可用。敵人技能預告只顯示其實際設定，不建立虛構技能。戰鬥框右上提供暫停、1×、2×選項，以文字括號與外框標示目前選擇。
- 10：技能獎勵、寶箱、事件、營火與結算放在中央主要內容區，選項及效果文字須完整可讀。挑戰成功或失敗結算時，直接顯示「重新挑戰」與「回主選單」按鈕；重新挑戰會重設本輪並進入起始地圖，回主選單沿用規則 11 的確認流程。
- 11：遺物獨立於玩家數值框外下方，單列橫跨左側主要區域，容器高度為 64；以固定 88×56 卡片、24×24 暫用圖示與下方名稱呈現，不換行，超出可見寬度時可橫向捲動。遺物列與其下方的速度控制保留垂直間隔；戰鬥紀錄固定於整體右側、玩家數值框下方，與遺物列頂部對齊並可垂直捲動。玩家數值框內的選單按鈕開啟獨立中央選單，提供返回、放棄本輪、設定、返回主選單，結算後另提供重新挑戰。設定顯示「設定尚未開放」；返回主選單先確認，確認後結束本輪，取消則保留本輪。
- 12：以 1280×720 參考畫面容納最多八名角色、普攻與六個技能槽及單列遺物。角色與技能保持固定大小且不捲動；遺物數量不受三格限制，超出可見寬度時橫向捲動；地圖與右側紀錄可垂直捲動；VS 始終在戰鬥區正中央，不隨兩方人數偏移。
- 13：生命、倒數與一般互動使用既有八色色票；鎖定框依使用者指定使用紅色 #E05B65，並配合「鎖定」文字；此額外狀態色僅適用 AdventureCanvas.prefab 的目標框，不延伸至生命或陣營。字級維持大、中、小三層。
- 14：圖示支援滑鼠懸停及鍵盤焦點提示，顯示名稱、技能等級、實際效果與即時狀態；提示窗跟隨滑鼠浮動，靠近畫面邊緣時翻轉方向並向內推，保持在畫面內，且不攔截游標。鍵盤焦點檢視仍將提示放在對應圖示附近。技能與遺物使用標準 Unity UI Image 方塊佔位，不以程式繪製圖案；下方常駐名稱。後續在 AdventureIconSprites.asset 對應識別碼的 Sprite 欄位拖入圖片，既有名稱、提示與倒數仍保留。
- 15：目前單人挑戰開啟選單及其子畫面時暫停，關閉後繼續；不據此替尚未實作的多人模式加入暫停。中央選單疊在目前挑戰畫面上方，以單層深色半透明遮罩保留底層 UI 可見並阻擋後方操作；遮罩不套用會疊加整片背景的外框效果。鍵盤導覽限制於目前選單。

## 原型行為與限制

- 1：戰鬥中查看地圖不會暫停戰鬥；顯示「戰鬥仍持續」的提示。領獎或結算時返回挑戰，回到原階段。
- 2：目前以文字與簡單幾何標記代表角色，已有可替換 Sprite 的方塊投射物佔位，尚無正式角色插圖與角色動畫；此佔位不代表正式美術技法已核定。
- 3：完整地圖的連線依現行原型規則呈現；複雜分支連線尚未擴充，多人選路投票已接入，見[單人可玩原型](AdventurePrototype.md)。
- 4：桌面懸停與鍵盤焦點已接入；觸控裝置的角色檢視方式仍待確認。

## 驗收情境

- 對應規則 1～3：開始挑戰後進入獨立地圖，可選節點會進入對應戰鬥或節點處理畫面；已選路徑與非可選節點狀態清楚。
- 對應規則 4、11：玩家數值框橫跨畫面，最左為本機玩家、最後為樓層；地圖與選單按鈕相鄰，遺物在框外下方，紀錄從框下方開始，不與數值框重疊。
- 對應規則 4、7：懸停敵人顯示目前動作與分隔的技能預告；下方維持玩家技能；點擊後出現紅框與鎖定文字，移開仍保留鎖定。
- 對應規則 5、12：一至四名玩家對四名敵人時，全部角色完整呈現，固定卡片不縮放且 VS 位於戰鬥區正中央。
- 對應規則 6～9：角色施放條顯示目前動作，技能卡可點擊並顯示冷卻與可用狀態；敵人預告依普攻次數更新；時間控制同時影響施放與投射物。
- 對應規則 10：成功與失敗結算皆直接顯示兩個按鈕；重新挑戰後生命、金幣、技能與遺物依新一輪設定重設，回主選單須確認後返回，取消則保留結算。非結算階段不顯示這兩個按鈕。
- 對應規則 10～12：可完整讀取技能獎勵效果、懸停查看遺物說明，並一次看見普攻與六個技能圖示；以 12 個遺物驗證同一橫列、尾端可捲動查看且不與速度控制重疊，紀錄常駐右側。
- 對應規則 11：進入地圖、戰鬥與結算時紀錄持續顯示；中央選單可返回、放棄、查看未開放設定及確認返回主選單，結算後可重新挑戰。單人開啟時戰鬥數值不變，關閉後繼續。
- 對應規則 14、15：移動滑鼠時 tooltip 持續跟隨，畫面四角均不超出邊界；開啟選單後仍能看見下方挑戰 UI，選單在最上層且無法操作背景。
- 對應原型行為 1：戰鬥中開啟地圖後戰鬥仍推進，不能操作下一列節點，返回後顯示當下戰鬥狀態。
